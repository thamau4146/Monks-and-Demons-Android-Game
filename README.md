# Monks and Demons Android Game

## Overview
Monks and Demons is an Android puzzle game based on the classic Artificial Intelligence problem known as the Missionaries and Cannibals problem. The objective is to safely transport three monks and three demons across a river using a boat that can carry only two characters at a time.

The challenge is that the number of demons must never exceed the number of monks on either side of the river, otherwise the monks will be eaten. Players must think logically and plan each move carefully to successfully solve the puzzle.

This project demonstrates how classical AI problems can be implemented as an interactive mobile application.

## Features
- Interactive puzzle gameplay
- Logical AI-based problem solving
- Simple and user-friendly interface
- State validation to prevent invalid moves
- Educational demonstration of an AI problem

## Game Rules
1. There are three monks and three demons on one side of the river.
2. The boat can carry at most two characters at a time.
3. Demons must never outnumber monks on either side.
4. The goal is to safely move everyone to the other side.
